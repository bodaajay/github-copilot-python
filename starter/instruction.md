# GitHub Copilot Project Instructions

## Code Style & Standards
- Use clean, PEP 8 compliant Python 3 code for Flask backend logic.
- Write modern JavaScript (ES6+) for frontend interactions.
- Maintain modular separation between backend logic (`sudoku_logic.py`), routes (`app.py`), and presentation (`templates/`, `static/`).
- All unit tests should be implemented using `pytest`.
